# 0012 全量出分、客观分确定性快路径与主观分直评

日期：2026-11-10
状态：已实施（R30）

## 背景

2026-11-09 的 run 92（KDK2，7 家 × 58 条 = 406 格）在 9.7 分钟内完成 350 格，
但仍有 56 格 `execution_failed`：count 24、subjective 24、c15 7、c42 1。
投标人 57 的标书中明明有 3 份 57 万/年的合同、ISO9001/14001/45001、
电子与智能化专业承包贰级、10 人团队表（电工证/登高证/职称/维修工程师）
以及 3 条增值服务，c52-c55、c57、c61、c62 仍然大面积 0 分或失败。

根因不是材料不存在，而是 managed 执行器的 count 路径把「事实抽取 + 逐条证据
ID 绑定」全部交给 LLM；任一 `source_id`/引文绑定失败、上下文超限或
`cert_section_present` 缺证据，整格就作废。确定性的合同/证书/人员/增值服务
解析此前只存在于 legacy 路径，managed 未接。

用户明确要求：

1. 每一个计分格都必须落实，不允许无分或执行失败；
2. 客观分按标书证据确定性计算（有业绩/证书/人员就加分）；
3. 主观分由大模型直评，即使不准确也要有分；
4. 继续提速。

## 决策

### 1. 闭合政策（provisional closure）

- 技术故障不再把整格留空。失败格写入一个显式的暂定分：
  - count/formula：0（或有确定性快路径结果时用快路径值）；
  - subjective：冻结档位最低档，无档位时 0；
  - veto/match：`concern`/`not_deeply_reviewed` 结论，不写数字分。
- 暂定格 `basis="fallback"`、`review_status="auto_confirmed"`、
  `machine_status="concern"`，warnings 落 `fallback_score` 结构；
  报告/矩阵/榜单显示「暂定」，并进入「兜底分清单」。
- 收尾闭合 pass 在价格前遍历所有未落定格，保证矩阵闭合；价格门槛读取
  已经落定的上游分数，价格不会因上游技术失败而整段跳过。
- 暂定分是**可见的暂定结论**，不是证据结论；正式报告允许发布，但页首和
  附录必须标注含 N 项暂定分、需人工复核。新建运行可重新计算，旧运行不改写。

### 2. 客观分确定性快路径

- 新增 `engine/material_inventory.py`：每家投标人构建一次、带页码的材料清单：
  - 合同/业绩：case_evidence 表路径 + 合同标题/金额/日期/发票/验收文本兜底；
  - 证书：认证证书页信号 + ISO/体系/电子与智能化/音视频集成等级；
  - 人员：PyMuPDF 团队表优先，文本行兜底；含姓名/职责/职称/证书/年限/经历；
  - 增值服务：真实章节标题后的编号/子标题/字母条目。
- 新增 `engine/objective_fastpath.py`：从冻结规则的名称/描述/params 确定性
  构建计分计划，复用 `score_count`/`score_count_tier`/`score_attribute_tier`
  等既有引擎；每个计划返回分数、计算过程和证据页；未检出=0 并注明。
- worker 在 OCR/LLM **之前**调用快路径；命中即短路（不建 collection、不调
  LLM），未命中才回退 LLM；LLM 失败再由闭合 pass 兜底。
- 不修改冻结 manifest/scoring_config；旧规则包无需重编译。
- 置信边界：相关章节未定位、合同金额不可读、表格字段整体为空时，快路径
  返回不完整并让 LLM 接手，避免把解析失败伪装成 0 分。

### 3. 主观分直评

- 新增 `BID_EVAL_SUBJECTIVE_DIRECT`（默认开）：主观格单轮、限页、一次 LLM；
  模型给出 0..满分 的分数即接受，不因缺引文/缺子项/部分页不可读整格失败。
- 引文仍逐条校验；校验失败的引文丢弃，保留分数。
- LLM 仍失败时按最低档/0 暂定，进入 fallback 清单。
- 证据、子项、`missing_evidence` 保留为审计/警告，不再作为完成闸门。

### 4. 范围与规则修正

- `rules/scope.py` 将「单位负责人为同一人 / 控股、管理关系的不同单位同时
  投标」纳入围串标留空范围（c15 类）；普通利害关系/关联设计单位条款不变。
- c61/c62 等「得 N 分」证书条款按规则文本路由到客观证书引擎；c38 这类
  被拆分的父级汇总 match 条目识别为重复汇总，标不适用，不重复计分。
- c42 低于成本报价仍按外部事实边界处理，不因技术失败留空。

### 5. 开关与回滚

- `BID_EVAL_SCORE_CLOSURE=1`（默认）：闭合暂定分；
- `BID_EVAL_SUBJECTIVE_DIRECT=1`（默认）：主观直评；
- `BID_EVAL_COUNT_DETERMINISTIC=on`（新运行默认）：客观快路径；
- 设为 0/off 可恢复旧行为。旧镜像不认 `basis=fallback/model`，回滚不要恢复
  旧镜像；用同镜像 + 开关回退，旧运行不改写。

## 后果

- 矩阵不再出现 `execution_failed` 空格；未定分项归零，改为显式暂定分。
- 客观分由确定性材料清单驱动，可逐项复核 calculation/证据页。
- 暂定分会影响排名，因此报告、榜单、矩阵必须同时展示「暂定」标识；
  人工复核后改分或重跑。
- 仍需持续校准人员经验/证书等级等确定性解析；解析不完整时交给 LLM，
  不以 0 分冒充确认缺失。
