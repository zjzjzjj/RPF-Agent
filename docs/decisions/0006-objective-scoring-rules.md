# 决策记录 0006：客观评分项的规则体系（材料链门槛 + 确定性检测 + 疑问兜底）

- 日期：2026-10-15
- 状态：已采纳
- 关联：0004（真实标书格式适配）、参考《浙江中烟…评审资料-发项目负责人.pdf》

## 背景

用户指出：资质/业绩/人员类**客观分**也应有明确的评分标准，不能全靠模型现场判断。
对照真实评审资料逐项复盘（run 10→16 回归：MAE 10.93→7.21），客观分的误差来源
是三类，全部可规则化。

## 客观分规则表（依据招标文件 + 真实评审执行口径）

| 评分项 | 计分规则 | 门槛/上限 | 证明材料（缺一不得分） |
|---|---|---|---|
| 投标人业绩 | 每案例 2 分 | 合同金额 ≥80 万；上限 6 | 合同复印件 + 发票复印件 + 业主证明（或验收材料） |
| 投标人认证及资质 | ISO9001/27001/20000 每项 1 分；CMMI≥2 级 1 分 | ISO 部分上限 3；总上限 4 | 证书复印件 + 全国认证认可平台查询截图 |
| 项目负责人经验 | 每案例 2 分 | 负责人 ≥5 年经验；上限 4 | 5 年经验证明 + 案例（合同须反映姓名，否则加业主证明） |
| 项目团队成员经验 | 每案例 1.5 分 | 上限 6 | 案例 + 姓名反映（或业主证明）+ 近六个月社保 |

**真实评审执行样例**（同一规则下的人工裁量差异，是系统设计的核心约束）：
- 先进数通：发票节为空、无验收材料 → 业绩 0；认证无查询截图 → 1 分
- 龙即：发票节同样为空，但有完整验收报告 → 业绩满分 6（评委据「或验收材料」放宽）
- 致成：团队成员合同无法体现人员 → 该 0；其余齐全
- **结论：材料齐全性在本项目人工执行中并不一致，AI 不能把「文本未见」直接扣成 0 分。**

## 决定

1. **确定性检测先行**（`engine/materials.py` 语义，落于 objective.py）：
   - 材料实质内容特征词：发票=`发票代码|发票号码|开票日期`；验收=`验收合格|验收报告|验收单|验收意见|验收通过|验收证明`；查询截图=`cnca.cn|认证认可|查询结果|有效状态`；社保=`社会保险|社保|参保`；5 年经验=`五年以上|5 年及以上|工作年限`
   - 节结构检测：案例按 `8.x.y 材料名` 分节（投标文件的通行组织方式），**节标题存在但节内无内页** = 材料未装订
2. **结论定级为「疑问线索」而非自动扣分**：材料缺失 → 该项标 `conflict_flagged` 疑问转人工（AI 不替评委做裁量性扣分）；有 LLM 逐案例核验（evidence 引文有效）时按核验结果计分并封顶
3. **LLM 核验的防作弊校验**：quote 与材料要求段重合/为空 → 该案例判定降为未提供（8B 模型实证作弊模式）
4. **全部计数项封顶/门槛进代码**：max_items、min_amount_yuan、per_item 由快照参数驱动，逐案例分支同样封顶（此前遗漏导致超满分）
5. **解析质量是前提**：材料检测的可靠性依赖内容解析覆盖——OCR 触发条件补充「字数少 + 大图」页（0006 同批修复：龙即 309 页、其他三家 14-17 页补 OCR）

## 决定（2026-10-16 补充：材料门槛自动执行）

用户指令：材料链缺失按因素规则自动计 0，材料列为计分条件。按项分流：

1. **业绩类**（逐案例核验已落地）：材料不全的案例不计入有效案例数（run 18 起生效）。
2. **认证类**：ISO 三体系与 CMMI 拆分计数（ISO9001/27001/20000 各 1 分上限 3，CMMI 1 分）。
   **查询截图门槛不做自动扣分**——文本层无法核验截图（截图页 OCR 后仅剩标题，真有截图的
   龙即也提取不到，2026-10-16 实证），自动清零会误杀。标 conflict 转人工核验原件。
3. **人员经验项（主观）**：招标原文材料硬门槛（5 年证明/姓名反映/社保）注入评审提示词，
   要求 LLM 逐条执行：无对应证明内容 → score=0（对齐真实评审对先数负责人 0、致成团队 0 的判法）。
4. **经验认知**：材料齐全性在人工评审中执行并不一致（同为发票节空，龙即凭验收报告满分、
   先数判 0）——系统自动执行「明示规则」（不得分条款）有依据；裁量性差异仍留人工。

## 后果

- 客观分的确定性部分（计数/门槛/封顶/公式）完全可复算；
- 材料齐全性的裁量部分：AI 出检测结论 + 疑问清单，人工终审（与 0003/0014 的「AI 不否决」哲学一致）；
- 报告疑问清单新增「材料链」类目（含节结构检测与特征词检测的证据）。
